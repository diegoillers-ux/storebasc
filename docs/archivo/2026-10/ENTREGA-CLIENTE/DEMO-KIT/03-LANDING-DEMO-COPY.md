Titulo: Plataforma de reservas para negocios de servicios
Subtitulo: Tu cliente agenda online y tu equipo administra todo desde un panel simple.
CTA principal: Ver demo

## Bloque 1 - Problema
Texto:
Coordinar agenda por chat consume tiempo, genera errores y reduce conversion.
Esta plataforma centraliza el proceso para que reservas, aprobaciones y confirmaciones ocurran en un solo flujo.

## Bloque 2 - Como funciona
1. Cliente selecciona servicio y horario.
2. Negocio recibe solicitud en panel admin.
3. Admin aprueba y confirma atencion.
4. Cliente recibe correo con detalles.

## Bloque 3 - Ventajas
1. Menos trabajo manual.
2. Mejor control de agenda.
3. Flujo claro para cliente y negocio.
4. Base tecnica lista para escalar.

## Bloque 4 - Ideal para
1. Consultorias y asesorias.
2. Centros de bienestar.
3. Negocios de citas y sesiones.
4. Emprendimientos que venden servicios con horario.

# Codebasicstor - Flyer Comercial (Editable)

## Solucion web para reservas y gestion de agenda
Una plataforma pensada para emprendedores que venden servicios y productos y necesitan organizar reservas sin procesos complejos.

## Propuesta de valor
- Agenda inteligente conectada a Google Calendar.
- Panel admin simple para aprobar reservas y enviar enlaces.
- Login seguro con Google para el administrador.
- Flujo operativo claro para cliente y negocio.
- Pasarela de pagos integrada (Mercado Pago Checkout Pro) + transferencia manual.

## Caracteristicas destacadas
1. Visual profesional y adaptable a marca.
2. Calendario de disponibilidad en tiempo real.
3. Reservas pendientes y aprobacion manual.
4. Envio de correo con enlace de sesion.
5. Configuracion de horario base y bloqueos.
6. Estructura lista para escalar catalogo y promociones.

## Beneficios para el negocio
- Menos mensajes manuales para coordinar agenda.
- Menos errores de doble reserva.
- Mejor experiencia para el cliente final.
- Control total desde un panel central.
- Base tecnica lista para crecer.

## Que recibe el cliente al adquirir el proyecto
1. Codigo fuente limpio (white-label).
2. Documentacion tecnica y manual de configuracion.
3. Lista de variables y credenciales requeridas.
4. Flujo funcional de reservas y administracion.

## Requisitos minimos de puesta en marcha
1. Cuenta Google del negocio.
2. Proyecto en Google Cloud con Calendar API.
3. OAuth 2.0 configurado.
4. Cuenta Gmail con App Password.
5. Variables de entorno cargadas.

## Mensaje sugerido para venta
"Te entregamos una plataforma de reservas profesional, personalizable y lista para operar. Incluye panel administrativo, integracion con Google Calendar y guia completa de implementacion para que puedas lanzar rapido y con control."
